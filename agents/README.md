# Agent definitions

This family preserves portable agent role definitions owned by the Handbook. Agent runtimes are integrations, not the category of this repository.

## Superpowers roles

[`superpowers/`](superpowers/) contains six owner-authored Pi-oriented role definitions recovered byte for byte after an unbacked configuration removal. Their content identities and recovery basis are recorded in [`provenance.json`](superpowers/provenance.json).

These files are inactive reference artifacts. The Handbook does not automatically install, register, link, adapt, or activate them. Their tool lists use Pi-oriented names, and `mem_save` requires a compatible memory integration. Any runtime adaptation or activation requires a separate approved decision and verification against the target runtime.

## Ownership and portability

The Handbook owns these definitions and publishes them under the repository [MIT License](../LICENSE). Consumers may read or adapt them under that license, but must independently supply compatible tools and validate execution semantics.

## Verification

The provenance inventory records the expected filename, byte count, and SHA-256 digest for every preserved definition. Verify those values directly before adapting or distributing a file.
